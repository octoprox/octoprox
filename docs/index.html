One proxy endpoint. Any pool behind it.

Octoprox accepts your client's requests and routes them through proxy pools you manage: cloud instances it provisions for you, provider sessions, your own static list, or devices on a WireGuard or OpenVPN tunnel. It verifies where each exit really is and meters what every pool costs you.

Web UI on localhost:8000, proxy on localhost:8080. Default login admin / admin.

Coming from Scrapoxy?

Scrapoxy was discontinued in February 2026: no images, no docs, no backend for GeoIP and health checks. Octoprox does the same job, self-hosted and Apache 2.0. The migration guide maps every Scrapoxy project, credential and connector to its Octoprox equivalent, and any vendor Octoprox lacks can be added as a YAML provider descriptor. Read the migration guide.

What it does

Everything you need to run a proxy pool as a service for your own scrapers and clients.

Cloud integrations

Provision proxy instances on AWS, GCP and Azure on demand, with auto-scaling driven by request rate and automatic rotation.

Smart routing

Round-robin, least-used, random, sticky session and health-based strategies, weighted connectors, per-connector domain filters and rate limits. Pick a session or an exit country per request from the proxy username.

Health monitoring

Automatic health checks with configurable intervals and thresholds; failing proxies are quarantined and released automatically.

TLS interception

Optional MITM mode with browser-grade TLS fingerprints, and an inspector for every intercepted request and response.

Metrics

Latency, success rate, request counts and traffic per proxy and per project, with history you can chart over hours or weeks.

IP attribution

Resolve every exit's country, state and city from MaxMind, DB-IP, IPinfo or IP2Location databases you host, verify what vendors claim, track each provider's accuracy, and reject sessions that exit in the wrong place.

Traffic limits and billing

Cap the bytes each connector carries per billing period, alert, block or cut transfers at the cap, and see what every pool costs from the price you pay per GB.

Tunnel devices

Routers, TVs, consoles and phones with no proxy settings join a project's pool through a WireGuard or OpenVPN tunnel Octoprox terminates. One config, QR code or profile per device.

REST API and dashboard

Full CRUD over projects, credentials, connectors and proxies, and a web dashboard for monitoring and configuration.
