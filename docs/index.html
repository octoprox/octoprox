Dynamic Proxy Management

An intelligent proxy aggregator that accepts client requests and routes them through managed proxy pools with cloud provider integrations.

Get Started View on GitHub

Features

Cloud Integrations

Dynamically provision proxy instances on AWS, GCP, and Azure with automatic setup.

Smart Routing

Round-robin, least-used, random, sticky session, and health-based routing strategies.

Health Monitoring

Automatic health checks with configurable intervals and failure thresholds.

Performance Metrics

Track latency, success rates, and request counts per proxy in real-time.

REST API

Full CRUD operations for managing projects, credentials, connectors, and proxies.

Web Dashboard

React-based UI for monitoring and configuration with real-time updates.
